PublicPath

Making public-sector opportunities easier to find.

I co-built PublicPath, a platform helping students and early-career candidates explore government careers. My work focused on API ingestion and data quality: cleaning, deduplicating, normalizing, and validating listings for search and filtering.

How a listing gets onto the site

  1. 1

    Schedule my work

    A GitHub Actions workflow starts ingestion on a daily schedule.

    PurposeA scheduled daily run, rather than manual pulls

  2. 2

    Ingest my work

    Python code requests listings from external job APIs.

    ResultRaw listings, each in its source’s own format

  3. 3

    Normalize my work

    Each source’s fields are mapped into one shared listing format.

    ResultListings that can be compared and filtered together

  4. 4

    Clean and deduplicate my work

    Listings are cleaned, and duplicates of the same listing are collapsed where they are detected.

    PurposeFewer duplicate listings

  5. 5

    Validate my work

    Listings are checked before they are used for search and filtering.

    PurposeCatch malformed records before use

  6. 6

    Store platform

    Listings are written to Postgres on Supabase.

    ResultOne queryable table of listings

  7. 7

    Search and filter platform

    The site lets visitors search and filter the stored listings.

    PurposeListings visitors can search and filter
