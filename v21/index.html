Ourea Brain

Company knowledge, accessible through Slack.

ForColleagues at Ourea Energy who need project context, owners, and decisions without searching several tools.

I built and deployed Ourea Brain, an internal AI assistant that brings company context into Slack. It connects information across Slack, Gmail, Google Docs, and meeting notes to help colleagues retrieve project context, identify owners, and follow up on decisions.

How it works

  1. A colleague asks a question in Slack.
  2. The app on Google Cloud Run receives it; credentials are held in Secret Manager. my work
  3. It draws on relevant company context and calls Anthropic’s Claude API. my work
  4. The response is posted back in Slack.

Simplified architecture.

PublicPath

Making public-sector opportunities easier to find.

ForStudents and early-career candidates exploring government careers.

I co-built PublicPath, a platform helping students and early-career candidates explore government careers. My work focused on API ingestion and data quality: cleaning, deduplicating, normalizing, and validating listings for search and filtering.

How it works

  1. Listings come from external job APIs.
  2. Python ingestion is scheduled to run daily with GitHub Actions. my work
  3. Data-quality steps clean, deduplicate, normalize, and validate listings. my work
  4. Listings are stored in Postgres on Supabase.
  5. The site’s search and filters read from that store.

CLARITY

Turning clinical notes into patient-friendly explanations.

ForA healthcare-AI research project exploring patient-friendly explanations of clinical notes.

I built a Python pipeline for the CLARITY healthcare-AI project that converts de-identified clinical-note JSON into patient-friendly explanatory videos, automating narration, slide generation, and MP4 production.

How it works

  1. Input: a de-identified clinical note in JSON.
  2. The pipeline produces explanatory content from the note. my work
  3. Narration is generated with Microsoft Neural TTS, and slides alongside it. my work
  4. Both are assembled into an MP4 video. my work
