Featured · 01

PublicPath

Making public-sector opportunities easier to find.

Role
Co-founder, Engineering and Data; one of two engineers
Tools
Python, GitHub Actions, Supabase, Postgres

I co-built PublicPath, a platform helping students and early-career candidates explore government careers. My work focused on API ingestion and data quality: cleaning, deduplicating, normalizing, and validating listings for search and filtering.

How listings flow

  1. External job APIs
  2. →
  3. Ingestion (my work)
  4. →
  5. Clean · dedupe · normalize · validate
  6. →
  7. Postgres on Supabase
  8. →
  9. Search and filters

Highlighted: my part. Simplified.

Technical notes
  • Ingestion is written in Python and runs on a daily GitHub Actions schedule.
  • Listings from different APIs are normalized before they are stored, so search and filters work on consistent fields.
  • Data lives in Postgres, hosted on Supabase.

Featured · 02

Ourea Brain

Company knowledge, accessible through Slack.

Role
Builder · Agentic AI Intern, Ourea Energy
Status
Built and deployed internally

I built and deployed Ourea Brain, an internal AI assistant that brings company context into Slack. It connects information across Slack, Gmail, Google Docs, and meeting notes to help colleagues retrieve project context, identify owners, and follow up on decisions. The application runs on Google Cloud Run and uses Anthropic’s Claude API; an early live deployment answered a Slack question using meeting-note context.

Simplified architecture

  1. Question in Slack
  2. →
  3. App on Google Cloud Run (built by me)
  4. →
  5. Company context + Claude API
  6. →
  7. Response in Slack

Context comes from Slack, Gmail, Google Docs, and meeting notes.
