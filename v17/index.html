Question 1

How do students and early-career candidates find government roles in one place?

What I built

PublicPath — making public-sector opportunities easier to find.

I co-built PublicPath, a platform helping students and early-career candidates explore government careers. My work focused on API ingestion and data quality: cleaning, deduplicating, normalizing, and validating listings for search and filtering.

Role
Co-founder, Engineering and Data; one of two engineers
Tools
Python, GitHub Actions, Supabase, Postgres
Live
Visit PublicPath at joinpublicpath.com ↗

How it works

  1. Pull listings from external job APIs on a schedule
  2. Clean, deduplicate, normalize, validate
  3. Store in Postgres on Supabase
  4. Serve search and filtering on the site

Simplified sequence.

Question 3

How can a clinical note become an explanation a patient can follow?

What I built

CLARITY — turning clinical notes into patient-friendly explanations.

I built a Python pipeline for the CLARITY healthcare-AI project that converts de-identified clinical-note JSON into patient-friendly explanatory videos. The workflow automates narration, slide generation, and MP4 production using Microsoft Neural TTS.

Context
Research Assistant, HOPE Lab, UChicago Booth
Tools
Python, Microsoft Neural TTS

How it works

  1. De-identified clinical note (JSON)
  2. Explanatory content
  3. Narration and slides
  4. MP4 video

Conceptual. Clinical material is not public, so no examples are shown.
