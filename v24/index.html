Ourea Brain

Company knowledge, accessible through Slack.

What it does

An internal AI assistant that brings company context into Slack for colleagues at Ourea Energy, designed to help them retrieve project context, identify owners, and follow up on decisions.

What I built

As an Agentic AI Intern, I built and deployed the assistant: the Slack-connected app on Google Cloud Run, its connections to company sources, and its use of Anthropic’s Claude API.

Observed behaviour

An early live deployment answered a Slack question using meeting-note context. It is an internal tool with no public link.

ToolsSlack integration · Anthropic Claude API · Google Cloud Run · Google Workspace sources · meeting-note integration · Secret Manager

CLARITY

Turning clinical notes into patient-friendly explanations.

What it does

Part of CLARITY, a healthcare-AI research project at HOPE Lab, UChicago Booth: turning de-identified clinical notes into patient-friendly explanatory videos.

What I built

As a Research Assistant, I built the Python pipeline that automates explanatory content, narration, slide generation, and MP4 production.

Output

MP4 explanatory videos. Clinical material is not public, so no example is shown.

ToolsPython · Microsoft Neural TTS
