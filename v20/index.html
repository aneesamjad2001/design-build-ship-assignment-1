01 · featured

Ourea Brain

Company knowledge, accessible through Slack.

For
Colleagues at Ourea Energy who need project context, owners, and decisions without searching several tools.
My part
Builder · Agentic AI Intern. I built and deployed the assistant; it connects information across Slack, Gmail, Google Docs, and meeting notes.
How it works
A question asked in Slack reaches the app on Google Cloud Run, which draws on relevant company context and Anthropic’s Claude API, then replies in Slack.
Evidence
An early live deployment answered a Slack question using meeting-note context.Internal tool; built and deployed internally.
Tools
Slack integration · Anthropic Claude API · Google Cloud Run · Google Workspace sources · meeting-note integration · Secret Manager

02 · featured

PublicPath

Making public-sector opportunities easier to find.

For
Students and early-career candidates exploring government careers.
My part
Co-founder, Engineering and Data; one of two engineers. My work focused on API ingestion and data quality: cleaning, deduplicating, normalizing, and validating listings for search and filtering.
How it works
Scheduled Python ingestion (GitHub Actions) pulls listings from external job APIs; data-quality steps prepare them; they are stored in Postgres on Supabase for the site’s search and filters.
Evidence
Project website ↗Job search was not loading when checked on 6 Oct 2026. The screenshot above shows the team’s product, not my individual work.
Tools
Python · GitHub Actions · Supabase · Postgres

03 · featured

CLARITY

Turning clinical notes into patient-friendly explanations.

For
A healthcare-AI research project at HOPE Lab, UChicago Booth, exploring patient-friendly explanations of clinical notes.
My part
Research Assistant. I built the Python pipeline that converts de-identified clinical-note JSON into patient-friendly explanatory videos.
How it works
Each note becomes explanatory content; narration is generated with Microsoft Neural TTS and slides alongside it; both are assembled into an MP4.
Evidence
Output format: MP4 explanatory videos.Clinical material is not public, so no example is shown.
Tools
Python · Microsoft Neural TTS
